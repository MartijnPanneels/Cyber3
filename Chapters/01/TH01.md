1. What is the swiss cheese model and how can it be applied to cybersecurity?

It is a multi-layered defensive strategy. Each layer in a cybersecurity strategy serves a distinct purpose, addressing different types of threats and vulnerabilities. Some layers are designed to prevent attacks, others to detect them, and yet others to respond to and mitigate their impact.

2.  What different type of network attacks exist?

    -   What is a (D)DoS attack?

    A Distributed Denail of Service Attack: When the target is made unable to deliver service to users due to unwanted or malicious traffic from an attacker (one or multiple hosts). The attacker depletes the resources of the target system for example bandwidth or processing power.

         Semantic Denail of Service Attack leverages on a characteristics of the misused protocol to hinder the service on the target. For example: Wasting computational power in a databwe by requesting intensive queries.

         Volumetrtic Attacks: generating a large volume of traffic or requests to exhaust resources or network connections. The target is be taking offlline.

    DDos Attacks needs to be coordinated to be effective, but can be shown in good protected monitoring.

    Reflection and Amplification Attacks: Reflection, the attacker sends crafted requests to the reflector using the source address of the target (spoofed requests). Amplification, bigger packets, means that higher traffic load will reach the target. To prevent spoofing, manage your network well.

        Attackers use open DNS ersolvers to increase traffic volume. A small DNS query can generate a very large DNS respone.

3.  DNS:

    1. What information can be enumerated from a DNS server?

        A/AAAA records (hostnames → IPs), MX records (mail servers), NS records (name servers), CNAME records (aliases), TXT records (SPF, DKIM, misc info), SOA record (admin email, timers), SRV records (service endpoints), PTR records (reverse lookups), Zone transfers (if misconfigured — full domain listing)

    2. When is it intended? What is considered a "normal" DNS resolve and how can you perform it using a CLI tool?

        A normal DNS resolve happens whenever a client looks up a domain to get its IP, (A/AAAA records).
        `dig google.com`, `nslookup google.com`, `host google.com`

    3. What is, and how can you perform a reverse lookup? What is meant by authoritative nameservers?

        A reverse lookup is to translate an IP to a domain name. Authoritive nameservers are servers that hold the official, original DNS records for a domain.
        `dig -x 8.8.8.8`, `nslookup 8.8.8.8`, `host 8.8.8.8`

    4. What is a zone transfer attack and why is it called an attack? Is a zone transfer always harmful?

        A DNS operation (AXFR) where a secondary nameserver copies the full DNS zone from the primary. If a nameserver allows anyone to request a zone transfer, an outsider can download all DNS records, revealing internal hosts and structure. Zone transfers are normal and necessary between authorized DNS servers. They are only harmful when misconfigured and accessible to the public.

4.  tcpdump (or alternatives)

    How can you create a network dump, only using the CLI, on a machine without a GUI?

    `sudo tcpdump -i eth0 -w capture.pcap`

    How can you exclude SSH traffic?

    `sudo tcpdump -i eth0 'not port 22' -w capture.pcap`

    How can you only include HTTP traffic?

    `sudo tcpdump -i eth0 'port 80' -w capture.pcap`
